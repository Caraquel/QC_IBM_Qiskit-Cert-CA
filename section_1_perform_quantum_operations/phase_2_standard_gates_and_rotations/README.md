# Phase 2: Standard Quantum Gates and Rotations

This notebook series is a focused practice track for the Section 1 Phase 2 certification material.

## Notebooks

- `2_1_1_Phase_Gates_and_Bloch_Sphere.ipynb`
  - Z, S, and T gates on `|0>`, `|1>`, and `|+>`
  - Relative phase versus global phase
  - Optional Bloch-sphere visualization
- `2_1_2_Rotation_Gates_and_Probabilities.ipynb`
  - `rx`, `ry`, and `rz` intuition
  - Exact statevector amplitudes
  - Measurement probabilities from rotations
- `2_1_3_Bell_State_and_Standard_Gates.ipynb`
  - Hadamard plus CX Bell-state construction
  - Measurement probabilities and phase checks
  - Optional qsphere and histogram plots
- `2_1_4_Phase_2_Exam_Drills.ipynb`
  - Short prediction drills
  - Fill-in-the-code practice
  - Outcome and probability checks

## Recommended Order

1. `2_1_1_Phase_Gates_and_Bloch_Sphere.ipynb`
2. `2_1_2_Rotation_Gates_and_Probabilities.ipynb`
3. `2_1_3_Bell_State_and_Standard_Gates.ipynb`
4. `2_1_4_Phase_2_Exam_Drills.ipynb`

## Notes

- Qiskit 2.x is assumed.
- The notebooks use `Statevector` so you can verify answers exactly without a backend.
- Visualization cells are optional and will safely skip if plotting dependencies are missing.
