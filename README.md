# QC Qiskit Certification CA

Qiskit v2.x certification preparation material organized as a section-by-section practice workspace.

## Repository Layout

- `section_1_perform_quantum_operations`
  - Python scripts and notebooks for Section 1
  - Includes `phase_2_standard_gates_and_rotations`
- `section_2_visualize_quantum_circuits_measurements_and_states`
  - Notebook series for circuit, measurement, and state visualization
- `section_3_create_quantum_circuits`
  - Notebook series for circuit construction, registers, parameters, and composition
- `section_4_run_quantum_circuits`
  - Notebook series for transpilation and local backend execution

## Getting Started

```bash
pip install -r requirements.txt
```

Open the notebooks in VS Code or Jupyter and work through each section in order.
